# 📊 Excel Sales Analytics Project

## 📌 Project Overview

This project is part of my Data Analytics learning journey, where I worked on a course-provided demo dataset to perform sales and financial analysis using Microsoft Excel. The project involved data cleaning and transformation using Power Query, followed by analysis and reporting using Pivot Tables and Excel. Also this project focuses on understanding business performance through reports, KPIs, trends, and comparisons.

---

## 🎯 Project Objectives

- Analyze customer-wise sales performance
- Compare market performance against targets
- Analyze Profit & Loss (P&L) across fiscal years
- Analyze P&L performance across different markets
- Analyze monthly sales and profitability trends
- Calculate and interpret key business metrics

## 📊 Reports Created

### 1. Customer Performance Report

Analyzed customer-wise Net Sales performance across fiscal years and calculated year-over-year growth.

### 2. Market Performance vs Target

Compared market-wise sales performance against the assigned targets.

### 3. P&L Statement by Fiscal Year

Analyzed:

- Net Sales
- COGS
- Gross Margin
- Gross Margin %

### 4. P&L Statement by Markets

Analyzed Net Sales, COGS, Gross Margin and Gross Margin % across different markets.

### 5. P&L Statement by Months

Analyzed monthly Net Sales, COGS, Gross Margin and Gross Margin % across fiscal years.
